\# Incident Tickets \& Runbooks



This repository contains simulated IT incidents focused on Azure and Linux troubleshooting.



Each incident documents the symptoms, investigation process, evidence, root cause, resolution, and prevention.



The scenarios are designed to simulate real-world Systems Administration and Cloud Operations tasks.



The goal is to practice structured troubleshooting and technical incident documentation.



Technologies covered include Azure, Linux, networking, PowerShell, identity, and cloud infrastructure.
